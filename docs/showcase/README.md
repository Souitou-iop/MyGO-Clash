# Showcase assets

The hero files are generated by `tools/showcase`; see that folder for the stage and capture scripts. The promo film was made separately with huashu-motion; its source is not in this repository.

| File | Used by |
|---|---|
| `hero-dark.gif` | Chinese README hero |
| `hero-light.gif` | Chinese README light-theme link |
| `hero-dark-en.gif` | English and Japanese README hero |
| `hero-light-en.gif` | English and Japanese README light-theme link |
| `hero-dark.png`, `hero-dark-en.png` | Poster stills |
| `hero-light.png`, `hero-light-en.png` | Light-theme poster stills |
| `hero-light.mp4`, `hero-light-en.mp4`, `hero-dark.mp4`, `hero-dark-en.mp4` | Release and landing-page material |
| `promo.webp` | Full-length animated preview of the promo (960 px, 15 fps, no sound) in all three READMEs, links to `promo.mp4` |
| `promo.mp4` | 30-second promo film with sound (1920×1080) |
